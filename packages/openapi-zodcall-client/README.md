# openapi-zodcall-client

Generate a [zodcall](https://github.com/nakita628/zodcall/tree/main/packages/zodcall) client from an
OpenAPI 3.x (`.yaml` / `.yml` / `.json`) or TypeSpec (`.tsp`) document.

## Usage

```bash
npm install zodcall zod
npm install -D openapi-zodcall-client

npx openapi-zodcall-client openapi.yaml -o src/client.ts
```

The generated file contains:

- every `components.schemas` as a zod schema (`PetSchema`)
- `api`, the `makeApi` definition: one endpoint per operation, aliased by `operationId`
- `createClient(baseURL, options?)`, a `Zodcall` instance for `api`

```ts
import { createClient } from "./client";

const client = createClient("https://api.example.com");

await client.listPets({ queries: { tag: "cat" } });
await client.getPet({ params: { petId: 1 } });
await client.createPet({ name: "pochi" });
```

## Config

Without arguments, `./openapi-zodcall-client.config.ts` is read (`-c <file>` names another one).
Node 22.18+ runs the `.ts` config natively.

```ts
import { defineConfig } from "openapi-zodcall-client";

export default defineConfig({
  input: "openapi.yaml",
  output: "src/client.ts",
  exportTypes: true, // export type PetSchema = z.infer<typeof PetSchema> (default: false)
  readonly: true, // component schemas are .readonly() (default: false)
});
```

Paths are resolved from the current directory.

### Mapping

- `{id}` in paths becomes `:id`
- `path` / `query` / `header` parameters become `Path` / `Query` / `Header`; parameters that are
  not required get `.exactOptional()`; `cookie` parameters are skipped
- the request body becomes the `Body` parameter: JSON, `multipart/form-data` (`form-data`),
  `application/x-www-form-urlencoded` (`form-url`), `text/*` (`text`) or `binary`
- the lowest `2xx` response is `response` (`z.void()` without content), with `status` when not 200
- other numeric status codes and `default` become `errors`

Schemas are generated by [oas-truth](https://github.com/nakita628/truth/tree/main/npm/oas-truth).
